# character_detail（予約資産レイヤ）

このディレクトリの実キャラ詳細設定ファイル（`character_detail_*.txt` / `.yml`）は
**Think-AI Lab. の予約資産**です。参考情報としてリポジトリに同梱していますが、コード（Apache-2.0）とは別に
**すべての権利を留保**しており、再利用のライセンスは付与しません（[LICENSE](./LICENSE) を参照）。

- このレイヤは現在 **コードからは未使用**です（キャラクターの人格はすべて `system_prompts/` が担います）。
  将来、外見・関係性・立ち絵などの追加情報を人格に反映するための **任意レイヤ** として使う想定です。
- 第三者がご自身のキャラクターを作る場合は、既存ファイルを再利用せず、独自の詳細設定ファイルを置いてください。
- ライセンス方針の詳細は、リポジトリ直下の [CHARACTERS.md](../../../CHARACTERS.md) を参照してください。
