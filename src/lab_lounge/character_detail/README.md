# character_detail（予約資産レイヤ）

このディレクトリに置かれる実キャラの詳細設定ファイル（`character_detail_*.txt` / `.yml`）は
**Think-AI Lab. の予約資産**であり、リポジトリのコード（Apache-2.0）とは別に
**すべての権利を留保**します。そのため `.gitignore` で意図的に追跡対象から外しています
（実体はローカルにのみ存在し、リポジトリには含まれません）。

- このレイヤは現在 **コードからは未使用**です（キャラクターの人格はすべて `system_prompts/` が担います）。
  将来、外見・関係性・立ち絵などの追加情報を人格に反映するための **任意レイヤ** として使う想定です。
- 第三者がご自身のキャラクターを作る場合、ここに独自の詳細設定ファイルを置けます（gitignore 済み）。
- ライセンス方針の詳細は、リポジトリ直下の [CHARACTERS.md](../../../CHARACTERS.md) を参照してください。
